# Caso studio — L'impatto economico e sociale dell'audiovisivo italiano

Pagina del caso studio OpenEconomics per APA — Associazione Produttori Audiovisivi
(dati 2023, aggiornamento marzo 2026).

**Online:** https://alessiogranella.github.io/oe-caso-studio-audiovisivo/

Repo pubblico, pagina esclusa dai motori di ricerca (`noindex` + `robots.txt`):
la vede solo chi ha il link.

## Struttura

- `index.html` — la pagina, statica e autonoma
- `js/charts.js` — motore dei grafici (SVG a runtime, tooltip, controlli segmentati)
- `js/data.js` — dati dei grafici, inline
- `ds-kit/` — token, font e componenti del design system OpenEconomics
- `assets/` — immagine della hero e logo del cliente

Sorgenti di generazione e dataset completi restano nel workspace, fuori da questo repo.
